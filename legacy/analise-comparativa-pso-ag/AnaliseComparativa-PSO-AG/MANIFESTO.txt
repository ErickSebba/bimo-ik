OBJETIVO
────────────────────────────────────────────────────────────────────────────────
Fornecer uma ferramenta científica completa para análise comparativa de três 
algoritmos de otimização (PSO, AG, PSO-DFL) aplicados ao problema de cinemática 
inversa em robôs 6-DoF.

TAMANHO E COMPARTILHAMENTO
────────────────────────────────────────────────────────────────────────────────
Tamanho da pasta: ~20-30 MB (sem resultados) / ~5-8 MB comprimido

Para GitHub:
  1. Comprima: Compress-Archive -Path . -DestinationPath AnaliseComparativa.zip
  2. A pasta analysis/results/ NÃO será enviada (veja .gitignore)
  3. Usuários geram seus próprios resultados com: python test_integrated_analysis.py

Para colegas (via email/WhatsApp):
  1. Comprima a pasta
  2. Envie AnaliseComparativa.zip (~8 MB)
  3. Eles descompactam e executam: python test_integrated_analysis.py
  4. Resultados são criados localmente na máquina deles

COMO USAR
────────────────────────────────────────────────────────────────────────────────
1. Descompactar a pasta
2. Instalar dependências: pip install -r requirements.txt
3. Executar: python test_integrated_analysis.py
4. Aguardar conclusão (30-60 minutos)
5. Coletar resultados em analysis/results/

SAÍDAS GERADAS
────────────────────────────────────────────────────────────────────────────────

  ├── fig_convergencia.png          → Convergência dos 3 algoritmos
