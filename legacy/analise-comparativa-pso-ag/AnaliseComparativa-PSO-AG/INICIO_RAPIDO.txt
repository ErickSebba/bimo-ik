[PASSO 1] Instalar Dependências
────────────────────────────────────────────────────────────────────────────────

  Windows:
  PS> pip install numpy scipy matplotlib seaborn scikit-opt

  Linux/Mac:
  $ pip install numpy scipy matplotlib seaborn scikit-opt

  Ou use requirements.txt:
  pip install -r requirements.txt


[PASSO 2] Executar a Análise
────────────────────────────────────────────────────────────────────────────────

  Abra um terminal na pasta do projeto e execute:

  PS> python test_integrated_analysis.py

  Tempo estimado:
  - Teste rápido (n_runs=3):  5-10 minutos
  - Padrão (n_runs=20):       30-45 minutos
  - Máxima precisão (n_runs=50): 60-90 minutos


[PASSO 3] Coletar Resultados
────────────────────────────────────────────────────────────────────────────────

[TROUBLESHOOTING]
────────────────────────────────────────────────────────────────────────────────

  Erro: "ModuleNotFoundError: No module named 'sko'"
  → pip install scikit-opt

  Erro: "UnicodeDecodeError"
  → Script só funciona em Windows por enquanto. Se usar Linux/Mac,
    remova caracteres acentuados dos prints.

  Script muito lento?
  → Reduza n_runs para 5 ou PSO_ITER para 50 (teste rápido)

  Gráficos não salvam?
  → Crie a pasta: mkdir -p analysis/results/{data,plots,statistics}
